# AI Harness · Bootstrap 5.3

## Порядок чтения

1. Открой [index.md](index.md) и выбери профиль по исходнику.
2. Выпиши UI-задачи и выбери канонические строки из каталога [Bootstrap 5.3](catalog/bootstrap-mapping.md) или [«Здоровье»](catalog/health.md) для целевого проекта.
3. Сверь [исключения](catalog/ignore-and-deprecated.md) и [имена токенов](tokens/summary.md).
4. Для сборки следуй [build-from-ds](.skills/build-from-ds/SKILL.md).
5. [DTCG](tokens/tokens-dtcg.json) открывай точечно по имени и режиму.

## Пять запретов

1. Не создавай дубликат компонента, вариант или обёртку для уже покрытой роли. Бери канонический компонент для целевого проекта.
2. Не добавляй сырые цвета, произвольные отступы, радиусы и размеры тап-зон. Используй подтверждённые семантические токены.
3. Не подменяй сетку, утилиты и переменные Bootstrap 5.3 локальными аналогами в проектах на Bootstrap. Не добавляй Bootstrap в проект с другой базой.
4. Не используй служебные, устаревшие и неподтверждённые компоненты в продуктовом UI. Допуск для черновика указан в каталоге.
5. Не передавай результат без проверки сценария, состояний, адаптации, доступности и привязок. Отметь отсутствующие источники и заблокированные роли.
