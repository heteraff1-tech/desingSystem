# Сборка по дизайн-системе

1. Прочитай [AGENTS.md](../../AGENTS.md) и [index.md](../../index.md). Запиши цель пользователя, вход, основное действие, ожидаемый результат и исключительные состояния.
2. Прочитай каталог нужного профиля — [Bootstrap](../../catalog/bootstrap-mapping.md) или [«Здоровье»](../../catalog/health.md) — и [исключения](../../catalog/ignore-and-deprecated.md). Выбери 3–5 компонентов для основной композиции. Для каждой роли запиши имя, профиль, вариант, источник и причину выбора. Используй одну каноническую запись на роль.
3. Определи целевой проект и формат. В Figma бери канон по ключу в каталоге. В Bootstrap 5.3 используй разрешённый класс для роли. Для `Custom` найди готовую обёртку в коде проекта. Проверь контракт и версию. Если продуктовый компонент или токен отсутствует, зафиксируй конкретный пробел.
4. Подбери привязки по [summary](../../tokens/summary.md). Значения или алиасы ищи точечно в [DTCG](../../tokens/tokens-dtcg.json) по имени токена или Figma-ключу. Учитывай активную тему.
5. Собери композицию. В Figma используй экземпляры по ключам, Auto Layout, Variables и Text Styles. В коде используй существующие обёртки, а в проекте на Bootstrap 5.3 — его сетку и допустимые классы из таблицы.
6. Проверь основной переход, ошибки, пустые и loading-состояния по брифу. Проверь фокус, клавиатуру, доступные имена, контраст, тап-зоны и переполнение. В Figma сверь ключи и привязки. В коде запусти проверки целевого проекта.
7. Передай результат с перечнем выбранных компонентов, проверенных состояний и незакрытых пробелов.
